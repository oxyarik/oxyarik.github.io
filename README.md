# Портфолио-шаблон — Инструкция по использованию

## 🚀 Как запустить

1. Откройте файл `index.html` в любом браузере (двойной клик или перетащите файл в браузер)
2. Или используйте локальный сервер: `python -m http.server 8000` и откройте `http://localhost:8000`

## 🎨 Настройка цветов и шрифтов

Откройте `style.css` и измените переменные в секции `:root`:

```css
:root {
    --color-accent: #2563eb;        /* Акцентный цвет (синий) */
    --color-bg: #ffffff;            /* Фон страницы */
    --color-text: #1a1a1a;          /* Основной текст */
    --font-family: system-ui, ...   /* Системный стек шрифтов */
}
```

Тёмная тема включается автоматически через `prefers-color-scheme`.

## ✏️ Замена контента

В `index.html` замените:
- **Имя и роль**: Найдите «Иван Иванов» и «Frontend-разработчик»
- **Email**: Замените `ivan@example.com` на ваш email
- **Соцсети**: Обновите ссылки на GitHub/LinkedIn в `href`
- **Текст «Обо мне»**: Отредактируйте 3 абзаца в секции `#about`

## 📁 Добавление проектов

Скопируйте блок `<article class="project-card">` в секции `#projects` и измените:
- Заголовок в `<h3 class="project-card__title">`
- Описание в `<p class="project-card__description">`
- Теги технологий в `.project-card__tags`
- Ссылку на проект в `href` у `.project-card__link`

Для добавления изображения проекта добавьте `<img>` внутрь `.project-card__image` или задайте `background-image` через CSS.

## 📱 Мобильное меню

Гамбургер-меню работает автоматически на экранах уже 768px. JavaScript обрабатывает:
- Открытие/закрытие меню
- Закрытие при клике на ссылку
- Закрытие по клавише Escape
- Закрытие при клике вне меню
