# 📊 Визуализатор задач с параметром

Интерактивный веб-инструмент для визуализации уравнений, неравенств и систем с параметрами. Предназначен для школьников 9–11 классов.

---

## 🚀 Как запустить

### Вариант 1: Локальный запуск (рекомендуется)
1. Откройте файл `index.html` двойным кликом в любом браузере
2. Для корректной работы требуется подключение к интернету (библиотеки загружаются через CDN)

### Вариант 2: Через локальный сервер
```bash
# Python 3
python -m http.server 8000

# Затем откройте в браузере:
http://localhost:8000
```

## 📖 Как использовать

### Базовое использование

1. **Введите уравнение/неравенство** в поле ввода
   - Примеры: `x^2 + a*x + 1 = 0`, `|x - 2| = a`, `sin(x) = a`

2. **Настройте параметр**
   - Измените имя параметра (по умолчанию `a`)
   - Используйте слайдер для изменения значения
   - Настройте диапазон (мин/макс)

3. **Наблюдайте за графиком**
   - Синяя линия — левая часть уравнения
   - Оранжевая линия — правая часть
   - Красные точки — решения (пересечения)
   - Зелёная область — решения неравенства

4. **Изучите анализ**
   - Тип выражения
   - Количество решений
   - Текстовое пояснение

### Кнопки управления

| Кнопка | Действие |
|--------|----------|
| 🔄 Обновить | Принудительно обновить график |
| 🔁 Сброс | Вернуть настройки по умолчанию |
| 📷 Сохранить скриншот | Скачать изображение графика |
| 🌓 Тема | Переключить светлую/тёмную тему |

## 📝 Поддерживаемые математические операции

### Операции
- Сложение, вычитание: `+`, `-`
- Умножение, деление: `*`, `/`
- Возведение в степень: `^`
- Модуль: `abs(x)` или `|x|`

### Функции
- Тригонометрические: `sin`, `cos`, `tan`, `cot`
- Обратные: `asin`, `acos`, `atan`
- Показательные: `exp`, `sqrt`, `log`, `log10`
- Другие: `abs`, `floor`, `ceil`, `round`

### Параметры
- Любая латинская буква кроме `x`, `y`, `e`, `i`
- По умолчанию определяется автоматически

---

## ⚠️ Известные ограничения

1. **Тригонометрические неравенства**
   - Не поддерживается автоматическое отображение нескольких периодов
   - Решение показывается только в видимой области графика

2. **Разрывные функции**
   - Функции типа `1/(x-a)` могут отображаться с вертикальными линиями в точках разрыва
   - Это артефакт численного метода отрисовки

3. **Сложные системы**
   - Поддерживаются только системы из двух уравнений вида `f(x) = g(x)`
   - Системы с тремя и более уравнениями не визуализируются

4. **Аналитический анализ**
   - Текстовые пояснения работают для типовых случаев
   - Для сложных уравнений показывается общая рекомендация

5. **Неявные уравнения**
   - Уравнения вида `F(x,y) = 0` требуют явного выражения `y = f(x)`
